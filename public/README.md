# `public/` — static files served as-is

Anything in this folder is served from the site root. e.g. `public/hero.mp4`
is available at `/hero.mp4`.

## Hero / footer background video

Upload your background clip here and name it exactly:

    public/hero.mp4

It will appear behind the hero and footer automatically — no code change.
If the file is missing, the site falls back to a branded dark gradient, so
nothing looks broken.

**Recommended clip:** a slow, MUTED, golden-hour drone glide over a modern
Perth home or new estate — 10–30 seconds, loops cleanly. It sits under a dark
overlay, so it reads as mood/texture rather than a feature. MP4 (H.264) is the
safest format; keep it under ~10 MB if you can so the page stays fast.

To upload via GitHub: open this `public/` folder in the repo →
**Add file → Upload files** → drop in your `hero.mp4`.
